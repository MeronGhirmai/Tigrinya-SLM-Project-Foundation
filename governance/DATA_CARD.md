# Data Card: Tigrinya (ትግርኛ) Multi-Domain Corpus
- Language: Tigrinya (tir, ISO 639-3), Ge'ez Script (Ethi, U+1200-U+139F).
- Sources: HornMT, XL-Sum BBC Tigrinya, MasakhaNEWS, TLMD.
- Normalization: Unicode NFC, Ge'ez full-stop canonicalization (::/፡፡ -> ።), wordspace normalization (፡ -> space), preservation of phonemic pharyngeals (ሐ, ዐ) vs glottals (ሀ, አ).
